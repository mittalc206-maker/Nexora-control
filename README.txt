NEXORA CONTROL MVP PWA

Files:
- index.html: application UI and local demo functionality
- manifest.webmanifest: installable web app metadata
- sw.js: basic offline cache
- icon.svg: app icon

IMPORTANT:
This is a front-end MVP prototype. Data is stored only in the browser on this device using localStorage. It has no real accounts, cloud database, multi-user sync, server-side security, or AI automation yet. Do not use sensitive or real customer data.

To install as an app:
1. Host the folder on an HTTPS static host (for example GitHub Pages).
2. Open the hosted URL in Chrome on Android.
3. Use Chrome menu > Install app or Add to Home screen (wording varies).
